# What feedback does Amazon actually send back for a Send?

Type: task
Status: open
Blocked by: none
Parent: ../map.md

## Question

Facts the feedback design needs, which only a live test gives (see [What exactly does Amazon accept by email to a Kindle address?](01-email-route-facts.md)). HITL checklist for the user, using Gmail in the browser:

1. Add the Gmail address to the Approved Personal Document Email List.
2. Send a small EPUB to the Kindle address. Note any reply (success email? verification request?) and how long delivery takes.
3. Send a PDF with subject "convert". Note whether it arrives reflowed.
4. Send a password-protected PDF (or another file that should fail). Note which inbox receives the failure notice and its wording.
5. Optional: send a small DOCX.

Record what arrived, where, and how fast.
